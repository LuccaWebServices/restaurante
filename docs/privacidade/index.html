Política de Privacidade

Modelo base, recomenda-se revisão por profissional jurídico.

Esta política explica como o site de Lume — Casa de Brasa trata dados pessoais. Foi escrita para refletir aquilo que o site faz realmente.

1. Responsável pelo tratamento

O responsável pelo tratamento é [DENOMINAÇÃO SOCIAL], NIF [NIF], com sede em [MORADA DA SEDE], que explora o restaurante Lume — Casa de Brasa (Rua da Fonte Velha, 27, 2780-000 Oeiras).

Contacto para questões de privacidade: [EMAIL PARA PRIVACIDADE].

2. Em resumo

  • Este site não usa cookies, ferramentas de estatística (analytics), publicidade nem píxeis de redes sociais.
  • Só são tratados dados pessoais nas situações descritas abaixo (alojamento do site e mapa, apenas se o carregar).

3. Alojamento do site e dados técnicos

O site está alojado no GitHub Pages, um serviço da GitHub, Inc. (Estados Unidos). Quando visita o site, os servidores da GitHub registam automaticamente dados técnicos, como o endereço IP, a data e hora do pedido e o tipo de browser, necessários para entregar as páginas e proteger o serviço contra abusos. Nós não usamos estes dados para o identificar.

  • Finalidade: disponibilizar o site de forma segura.
  • Base legal: interesse legítimo (art. 6.º, n.º 1, alínea f) do RGPD).
  • Conservação: pelo período definido pela GitHub (ver a Declaração de Privacidade da GitHub (abre num novo separador)).
  • Transferências internacionais: a GitHub pode tratar dados fora do Espaço Económico Europeu, com as garantias previstas no RGPD (por exemplo, o Quadro de Privacidade de Dados UE-EUA ou cláusulas contratuais-tipo).

4. Preferências guardadas no seu dispositivo

O site guarda no armazenamento local do browser (localStorage), apenas no seu dispositivo:

  • o idioma que escolheu (português ou inglês);
  • o tema visual escolhido na versão de demonstração;
  • a sua escolha de carregar o mapa automaticamente, se assinalar «Lembrar a minha escolha».

Estes dados não são cookies, não são enviados para nenhum servidor e não servem para o identificar. São estritamente necessários para a funcionalidade que pediu. Pode apagá-los a qualquer momento nas definições do browser (dados de sites).

5. Mapa da Google

O mapa da Google só é carregado se clicar em «Carregar mapa». Até lá, nenhum dado é enviado à Google. Ao carregá-lo, a Google Ireland Limited recebe o seu endereço IP e pode definir cookies, enquanto responsável pelo tratamento independente, nos termos da Política de Privacidade da Google (abre num novo separador).

Base legal: o seu consentimento (art. 6.º, n.º 1, alínea a) do RGPD). Se assinalou «Lembrar a minha escolha», pode retirar o consentimento apagando os dados deste site no browser.

Ligações para outros serviços

O site tem ligações para serviços de terceiros (por exemplo, plataformas de reserva e de entregas, WhatsApp, redes sociais e aplicações de mapas). Ao clicar, sai deste site e passa a aplicar-se a política de privacidade desse serviço.

Os seus direitos

Nos termos do RGPD, pode pedir o acesso, a retificação, o apagamento, a limitação do tratamento e a portabilidade dos seus dados, opor-se ao tratamento e retirar o consentimento a qualquer momento, sem afetar o tratamento já realizado. Para isso, escreva para [EMAIL PARA PRIVACIDADE]. Respondemos no prazo máximo de um mês.

Reclamações

Se considerar que os seus dados não foram tratados corretamente, pode apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD) (abre num novo separador).

Alterações a esta política

Esta política pode ser atualizada quando o site mudar. Última atualização: 23 de outubro de 2026.
